# Bridge Collective | Responsive Landing Page

A responsive landing page built as a Frontend Mentor challenge.

## Overview

The project features a clean, modern layout with a responsive grid, statistics cards, and an interactive navigation menu.

## Built With

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox

## Features

- Responsive layout for mobile, tablet, and desktop
- Interactive hamburger menu
- Accessible navigation with ARIA attributes
- Background overlay when the navigation menu is open

## What I Learned

During this project, I practiced building responsive layouts with CSS Grid and Flexbox, organizing styles, and implementing basic JavaScript interactions.

I also used Stylelint to check CSS code quality and improve consistency.
